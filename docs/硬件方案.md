## 零、2026-10 市场背景（必读）

当前处于 AI 引发的**存储超级涨价周期**，这彻底改变了装机策略：

| 部件 | 2025 年价格 | 2026-10 现价 | 涨幅 |
|---|---|---|---|
| DDR5 64GB 套条 | ¥1,000–1,200 | **¥4,000–8,000+** | 4–7 倍 |
| DDR5 32GB 套条 | ¥500–600 | ¥1,600–2,600 | 3–4 倍 |
| 1TB NVMe SSD | ¥400–500 | **¥1,100–1,300** | 2.5 倍 |
| 二手 RTX 3090 | ¥4,000–5,000 | **¥5,500–7,500** | +40% |
| DDR4 32GB 单条 | ¥300–400 | ¥1,100–1,400 | 3 倍 |

- 原因：HBM 挤占 DRAM 晶圆产能，三星 33% 产线转 HBM；机构预计**短缺持续到 2027 年**，Q4 合约价还要继续涨
- 结论：**等待没有意义，早买早锁价；内存买最小够用，先 32GB 起步**

## 一、实测资源消耗（满血版 qwen3.8-27b-full，249K 上下文 + 视觉 + 投机解码）

| 资源 | 实测 | 说明 |
|---|---|---|
| **GPU 显存** | **23,280 / 24,576 MiB（95%）** | 硬性瓶颈。权重 17.2GiB + KV 池 249,856 token（rk4v4 量化）+ DFlash2 草稿 + 视觉 overlay |
| GPU 功耗 | 待机 11W / 满载 **330W**，100% 利用率 | 400 token 生成全程采样，SM 时钟 ~1560MHz |
| GPU 计算 | decode 65–321 tok/s；prefill 806–2,263 tok/s | 原创内容慢、复述/工具调用快（投机解码接受率 20–60%） |
| CPU | 引擎平均只占 **1 核的 13%** | 纯 GPU 负载；但 agent 侧（node/dsh/工具/浏览器）吃多核 |
| 内存 | 引擎 RSS 12GB + dsh/bili 全家桶 7.7GB | **整机 32GB 可跑，64GB 宽裕**（本机 376GB 属浪费） |
| 磁盘 | 模型 18GB + 引擎 0.6GB + 运行时 1GB | 启动加载 536MiB/s，NVMe 约 35 秒；总需求 ≥60GB |
| 网络 | 可忽略 | 全部本机回环，局域网分享走千兆即可 |

**结论：这是一门"显存生意"**。算力决定快慢，但**24GB 显存是能不能跑满血版的唯一门槛**。

## 三、不变的核心结论（涨价也改不了的事实）

1. **显存 ≥24GB 是硬门槛**（实测占用 23,280/24,576 MiB），3090 仍是唯一便宜解
2. **CPU 甜点级即可**：引擎只用 13% 单核；7500F/5700X 的单核比老 Xeon ES 还快，agent 更跟手
3. **电源 850W 金牌是底线**（330W 满载 + 500W 尖峰）
4. **内存 32GB 底线、64GB 宽裕**——但 2026-10 的价格下，先 32GB 或买二手工作站整机
5. 装机必做：显卡双独立供电线 / 关睡眠 / FurMark 验显存温度 / 二手内存 MemTest 过夜

## 四、性能预期（同 GPU 即同性能，与方案无关）

decode 短回复 150–320 tok/s、长文 65–90 tok/s；prefill 800–2,260 tok/s；缓存命中 TTFT <2s；满载整机 ~450–500W；每天 8 小时 ≈ ¥2.5 电费。
