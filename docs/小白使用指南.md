# dsh 使用指南（小白版）

> 服务器重启后，按这个来，不用懂任何技术。

## 一、服务器开机后要做什么？

**什么都不用做，等 3 分钟。** 所有服务都会自己启动好（模型加载需要约 2 分钟）。

想确认好没好：看桌面右下角时间，开机超过 3 分钟就肯定好了。

## 二、我自己在这台服务器上怎么用？

1. 双击桌面上的 **「启动dsh（AI对话）」** 图标
2. 它会自动检查服务、稍等片刻后打开浏览器
3. 在打开的网页里，右下角模型选 **Qwen3.8-27B**（两个名字都行，是同一个模型）
4. 直接打字聊天、粘文件、贴图片都可以

## 三、同事在其它电脑上怎么用？

1. 在服务器桌面上找到文件 **「dsh-web地址.txt」**，打开它
2. 把里面的网址（`http://192.168.1.100:13080/?token=<启动后见 dsh-web 日志>`）发给同事
3. 同事在自己电脑的浏览器打开这个网址就能用，模型选法一样

⚠️ 注意：**服务器每次重启后，这个网址里的 token（口令）都会变**。同事打不开时，先看服务器上这个 txt 文件里的最新地址。

## 四、常见小问题

| 问题 | 解决办法 |
|---|---|
| 双击图标后浏览器没打开 | 再双击一次；或手动打开浏览器输入 txt 里的地址 |
| 网页打不开、提示 401 | 地址过期了，重新打开 txt 复制最新地址 |
| 回复特别慢 | 正常，模型每轮要思考几秒到几十秒；超过 3 分钟没反应再重试 |
| 想重新开始对话 | 点左侧「新会话」 |
| 完全用不了 | 喊管理员（或运行 `ninfer-ctl` 看状态面板） |

## 五、一句话原理（可跳过）

模型跑在这台服务器的显卡上，dsh 是它的聊天界面。双击图标 = 检查模型醒没醒 → 帮你打开聊天网页。
